Agents pop into the chat only when they're needed

The same Claude Code-style chat, with no agent list. When Bob's agents start working, each one appears as its own little character with a live status. When it finishes, it shrinks into one line, so the chat stays clean.

Plays automatically, about 50 seconds per loop.
