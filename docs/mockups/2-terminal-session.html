Interactive mode mockup

Type cx and everything happens in one session

Like Claude Code: it opens with the logo, signs you in, connects GitHub, then gives you a prompt. You say what you want, pick a repo, and it runs the whole flow, asking you only when it needs a decision. While it works, you can keep chatting with Bob.

The full session is shown below. Press Play to watch it run.
~ — cx

Where we are

1Open and sign in
2Connect GitHub
3Pick a repo
4Bob reads and starts the app
5Approve rules
6Search and shrink
7Bob explains and fixes
8Verify and open PR

Slash commands

/reposwitch repo
/rulesview or edit rules
/runsearch for bugs
/replayreplay a counterexample
/explainask Bob why
/verifyprove a fix works
/dashboardopen the web view
/loginswitch account

You can also type in plain words, like "find bugs in my refund flow" or "why did it break?". Bob understands those.

Chat while it runs

The search runs in the background, shown in the bar at the bottom of the terminal. You can ask Bob anything meanwhile. Bob answers from the live run data and logs, and it never decides pass or fail.

It only stops for decisions

Missing setup values, approving rules, what to do after a bug, and applying a fix. Everything else runs on its own. cx --auto skips the questions and only opens PRs for you to review.

CI still works

The same tool runs without the chat for pipelines: cx run --ci exits pass or fail.
